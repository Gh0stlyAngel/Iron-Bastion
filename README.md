# Iron Bastion

Minimalist 3D tower defense game developed with **Unity 6 LTS** for **Android**.

Build defensive towers, manage your gold, and stop enemy waves before they reach your base.

---

## 📱 Main Menu

![Main Menu](Screenshots/MainMenu.jpg)

Simple interface with:

- Play
- Sound settings
- Background music

---

## 🏰 Gameplay

![Gameplay](Screenshots/Gameplay.jpg)

Defend your base by placing towers strategically.

Features:

- Wave-based gameplay
- Gold economy
- Build and sell towers
- Pause menu
- Victory & defeat screens

---

## ⚔️ Towers

Three tower types with different roles:

- 🏹 **Archer Tower** – fast physical damage.
- 💣 **Cannon Tower** – slow area-of-effect damage.
- ✨ **Mage Tower** – magic damage that ignores armor.

---

## 👾 Enemy Types

Fight against enemies with different behaviors:

- Grunt
- Runner
- Flying Enemy
- Tank

Each type requires a different defensive approach.

---

## 📈 Progression

![Gameplay](Screenshots/Gameplay2.jpg)

Survive all enemy waves while managing your resources efficiently.

Gold earned from defeated enemies can be spent on new towers.

---

## 💀 Defeat Screen

![Defeat](Screenshots/Defeat.jpg)

The game ends when enemies reduce the base HP to zero.

Players can instantly:

- Restart the level
- Change sound settings
- Return to the main menu

---

## 🎮 Controls

| Action | Input |
|--------|-------|
| Build Tower | Tap Build Spot |
| Sell Tower | Tap Tower |
| Start Waves | Play Button |
| Pause | Menu Button |

---

## 🛠 Tech Overview

- Unity 6 LTS
- C#
- Mobile Input System
- ScriptableObject-based wave configuration
- Event-based UI updates
- Modular tower system
- Object-oriented design
- Android build
